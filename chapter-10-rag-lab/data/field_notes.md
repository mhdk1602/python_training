# Field Notes on Short-Form Content

I use this note file in the capstone for one reason: learners should see that a retrieval pipeline does not care whether the upstream content came from an API, a CMS export, or a notebook draft.

## Weekend planning heuristics

- If the trail note mentions shuttle dependency, treat arrival time as a hard constraint.
- If the content sounds family-friendly but never mentions terrain, do not trust the tag yet.
- Accessibility language is often buried in logistics text rather than the title.

## Notes for the answer layer

When I inspect retrieval output, I want to know two things quickly. First, which source chunk won. Second, whether it won because of semantic similarity or because metadata narrowed the field before similarity mattered.
